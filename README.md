# GramVarsha

Terrain-aware rainfall/temperature downscaling with crop-specific advisories
for panchayats around Sangli, Maharashtra.

## Stack
- Next.js 16 (App Router, Turbopack)
- React 19, Tailwind CSS 4
- Leaflet for the map

## Local dev
```bash
npm install
npm run dev
```

## Deploy
Deployed on Vercel — connect this repo to a Vercel project and it will
auto-detect the Next.js framework.
